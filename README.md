## 🚀 Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/maiagit/aulas-de-ingles.git
```

Entre na pasta:

```bash
cd aulas-de-ingles
```

Abra o arquivo `index.html` em seu navegador.

Para uma melhor experiência durante o desenvolvimento, utilize a extensão **Live Server** no Visual Studio Code.

---

## ⚙️ Personalização

As principais informações podem ser alteradas facilmente no arquivo `script.js`, como:

- Número do WhatsApp
- Link do Instagram
- Mensagem padrão do WhatsApp

Também é possível substituir facilmente as imagens da pasta `images/` para personalizar totalmente o site.
